# EnderIO Upgrade

An upgrade of [Ender IO](https://github.com/Team-EnderIO/EnderIO) for **NeoForge** (Minecraft 1.21.4 / NeoForge 26.1.2).

## About

This repository is an upgraded port of Ender IO to modern NeoForge. It is a multi-project Gradle build containing:

- `endercore` — core library
- `enderio` — main mod
- `enderio-modded-conduits` — modded conduits integration

## Prerequisites

Before contributing, ensure you meet the [NeoForge prerequisites](https://docs.neoforged.net/en/latest/gettingstarted/#prerequisites):

- **JDK 21** (NeoForge 26.1.2 requires Java 21)
- **Git**
- Your preferred IDE (IntelliJ IDEA recommended)

## Getting started

1. **Fork this repository** under your own GitHub profile so you can push changes and open Pull Requests.
2. **Clone your fork:**

   ```bash
   git clone https://github.com/<your-profile>/enderio-upgrade.git
   cd enderio-upgrade
   ```

3. **Open the project in your IDE** and wait for the Gradle import to finish.
4. **Follow the NeoForge IDE setup** for your IDE: https://docs.neoforged.net/en/latest/gettingstarted/#from-zero-to-modding

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) for the full contributing guide.

### Quick summary

- **Before selecting a task** from the issue tracker, comment on the issue to say you are working on it so others don't duplicate the effort.
- **Planning something not tracked?** Either open an issue to discuss your proposal, or push an early draft Pull Request for discussion.
- **Work in small, focused commits** — try to commit for each major thing you do.
- **Create a draft Pull Request early** for big changes to receive early feedback.
