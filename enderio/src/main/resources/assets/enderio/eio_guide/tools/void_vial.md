# Vial of the Void

<Column alignItems="center" fullWidth={true}>
  <RecipesFor id="void_vial" />
</Column>

The vial of the void is an item that absorbs experience from when in the main or off-hand. 
It only absorbs experience in world, and can not take experience from the player, similar to the Mending enchantment. 
To take experience from the player, use the <ItemLink id="experience_rod" /> or <ItemLink id="xp_obelisk" />.
The player can use the vial on themselves to get the stored experience, 
or empty it as <ItemLink id="xp_juice_bucket" /> in a fluid container like the <ItemLink id="fluid_tank" />.
