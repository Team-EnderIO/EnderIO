# Yeta Wrench

<Column alignItems="center" fullWidth={true}>
  <RecipesFor id="yeta_wrench" />
</Column>

The yeta wrench (or other wrenches with the correct tag) can be used to change the IO-mode on the side of a machine, or fully pickup the machine with energy and items.
