# Redstone Conduits

<Column alignItems="center" fullWidth={true}>
  <Recipe id="redstone_conduit" />
</Column>

<ItemLink id="conduit" components="enderio:conduit='enderio:redstone'"/>'s are conduits that transport redstone signals. 
There are several color coded channels that carry independent signals. These channels also interact with the redstone channels defined in other [conduits](../conduits.md).
<ItemLink id="redstone_not_filter" />'s can be used to apply logic to the conduit in-or outputs.
