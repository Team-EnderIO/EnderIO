# Conduit Facades

Conduit facades are used to hide conduits in world. They can be painted using the <ItemLink id="painting_machine"/>. 
Holding any [conduit](../conduits.md) or <ItemLink id="yeta_wrench"/> will turn the facades transparent to make it easier to see and select conduits in the network.
