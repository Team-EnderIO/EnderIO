# Soul Binder

The soul binder can be used to infuse a mob soul captured in a  <ItemLink id="soul_vial" /> into other items and machines. 
The machine uses both energy and experience to infuse the souls. 
The amounts needed to depend on the type of soul used, while the speed is determined by the <ItemImage id="basic_capacitor" /> [capacitor](../misc/capacitors.md).
